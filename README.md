## 🌐 Visión Ejecutiva del Proyecto

**Villeta Conserje** es una solución digital diseñada para conectar a propietarios de fincas campestres y casas de recreo en la región del Gualivá con un servicio integral de administración hotelera bajo estándar de **Superanfitrión en Airbnb**:

- **Comercialización de Alto Rendimiento:** Estrategias de precios dinámicos y posicionamiento preferencial para maximizar ocupación e ingresos en fines de semana y temporadas altas.
- **Operación 360°:** Protocolos de limpieza profunda de 47 puntos, lencería hotelera de alta gama, supervisión de personal, mantenimiento de piscinas y zonas verdes.
- **Experiencia de Huésped:** Asistencia y hospitalidad de conserjería 24/7 para garantizar evaluaciones consistentes de 5 estrellas.
- **Captación Directa:** Canal digital de conversión diseñado para resolver las dudas financieras y operativas de los propietarios interesados en rentabilizar sus inmuebles.

Sitio oficial en producción: **[villetaconserje.com](https://villetaconserje.com)**

## ⚡ Capacidades del Sistema

| Módulo | Función Principal |
| :--- | :--- |
| **Formulario de Valoración Resiliente** | Sistema de captura de prospectos con validación de datos y contingencia directa hacia WhatsApp VIP sin interrupción ni alertas de error para el usuario. |
| **Calculadora de Ingresos** | Herramienta interactiva que proyecta el potencial económico de fincas según capacidad y porcentaje de ocupación estimada. |
| **Motor de Blog y Contenidos** | Publicación de artículos educativos sobre agroturismo, tributación, normativas RNT y rentabilidad de fincas vacacionales. |
| **SEO Local & GEO Ready** | Arquitectura con datos estructurados JSON-LD (`RealEstateAgent`, `LocalBusiness`), Open Graph de alta resolución y favicons adaptados a Google Search. |
| **Optimización de Medios WebP** | Pipeline de imágenes responsivas en formato WebP para tiempos de carga ultrarrápidos y Core Web Vitals en verde. |
| **Módulo de Gestión Interna** | Panel privado para administración de propietarios, contenidos y seguimiento de rendimiento orgánico. |

## 🛠️ Stack Tecnológico

- **Frontend Core:** Next.js 14.2 (App Router, Server & Client Components)
- **Biblioteca de Interfaz:** React 18 + TypeScript 5 (tipado estricto)
- **Diseño & Estilos:** Tailwind CSS 3.4 con sistema de diseño a medida (paleta de hospitalidad y lujo campestre)
- **Micro-animaciones:** Framer Motion
- **Optimización de Recursos:** Sharp + next-image-export-optimizer
- **Entrega y Analítica:** Google Search Console API + EmailJS SDK + Supabase Client

## 🔧 Mantenimiento y Desarrollo Interno

> *Nota: Esta sección es exclusiva para el equipo técnico autorizado a cargo del mantenimiento de la plataforma.*

### Comandos de Operación

```bash
# Servidor local de desarrollo (http://localhost:3000)
npm run dev

# Compilación y optimización de producción
npm run build

# Análisis de código y tipos TypeScript
npm run lint

# Auditoría de rendimiento en Google Search Console
npm run gsc:analyze
```

### Configuración del Entorno
Las claves privadas de servicios (EmailJS, Supabase y Google APIs) se gestionan a través del archivo local `.env.local` (excluido del control de versiones por seguridad).
