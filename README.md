## 📌 Descripción del Proyecto

**Villeta Conserje** es una solución digital diseñada para conectar a propietarios de fincas de recreo y viviendas turísticas con servicios de administración especializada, mantenimiento preventivo, supervisión de personal y disponibilidad operativa 24/7.

El objetivo técnico del proyecto es ofrecer un portal rápido, ligero y completamente responsivo, enfocado en la conversión, el posicionamiento local y la atención al cliente directa vía mensajería instantánea.

---

## 🛠️ Stack Tecnológico

* **Frontend:** HTML5 semántico, CSS3 modular (diseño adaptable a móviles y escritorio) y JavaScript para interacciones dinámicas.
* **Integraciones:** Enlaces directos a canales de atención vía WhatsApp API y formularios de contacto.
* **Control de Versiones:** Git y GitHub para gestión de ramas y trazabilidad de cambios.
* **CI/CD & Despliegue:** Flujo automatizado con **GitHub Actions** (`build-and-deploy`) para sincronización y publicación continua en servidor de hosting.

---

## ✨ Características Principales

* 📱 **Diseño 100% Responsivo:** Adaptado para navegación fluida en smartphones, tablets y ordenadores.
* ⚡ **Carga Rápida & Rendimiento:** Estructura limpia y optimización de recursos gráficos para navegación fluida.
* 📍 **Enfoque en SEO Local:** Arquitectura de contenido orientada a búsqueda local de servicios en la región de Villeta y Cundinamarca.
* 💬 **Llamadas a la Acción (CTA):** Comunicación directa con el gestor de la propiedad a través de un clic hacia WhatsApp.
